# R6 bridge derivation: LSWT bands to trajectory OAM

Status: convention resolved and oracle-validated. The derivation is the
`[OAM-R6]` prerequisite for B5.4. The independent reciprocal-supercell oracle
now validates the particle-field bridge with an analytic spatial derivative;
the production per-sublattice trajectory mesh remains a separate diagnostic
and is not identified with `F_n`.

## 1. Conventions and the HP map

Let a site be `r_(R,s) = R + tau_s`, where `R` is a Bravais-cell position and
`s = 1..NA` labels the site in the cell. UppASD's `setup_ektij` uses the
site-position Fourier factor

```
    exp(-i k . r)
```

so the corresponding real-space reconstruction uses `exp(+i k . r)`. The
`k` in this statement is the Cartesian physical wave vector; the Hamiltonian
interface receives `q = k/(2*pi)`. Reversing both transforms is harmless, but
reversing only one of them changes the sign of the trajectory winding.

Write the positive-energy Colpa column as

```
    T_n(k) = ( u_n(k) )
             ( v_n(k) )
```

with

```
    A_k = (a_(1,k), ..., a_(NA,k), a^dagger_(1,-k), ..., a^dagger_(NA,-k))^T
    B_k = (b_(1,k), ..., b_(NA,k), b^dagger_(1,-k), ..., b^dagger_(NA,-k))^T
    A_k = T(k) B_k.
```

For a coherent packet in band `n`, with amplitude `beta_n(k)`, the transverse
spin field generated by one positive-frequency packet is therefore, to linear
HP order,

```
 <a_s(r,t)> = integral dk [ u_sn(k) beta_n(k) exp(+i k.r - i E_n(k)t/hbar)
                           + v_sn(k)^* beta_n(k)^*
                             exp(-i k.r + i E_n(k)t/hbar) ].
```

The second term is not optional: it is the hole component of the same Nambu
mode. The displayed form assumes the packet is represented by the `b_(n,k)`
component; an implementation may equivalently construct the full Nambu field
first and then take its particle block.

For spins of length `S_s`, Holstein--Primakoff gives

```
    S_s^+ = S_x + i S_y = sqrt(2*S_s) a_s + O(a^dagger a a),
```

and hence the C1 field used by trajectory OAM, whose `m` is a unit moment
direction, is

```
    psi_s(r,t) = m_x + i m_y = <S_s^+>/S_s
                = sqrt(2/S_s) <a_s(r,t)>.
```

If an unnormalised spin field is used instead, its prefactor is
`sqrt(2*S_s)`. This distinction changes the norm but not a lambda ratio when
`S_s` is uniform. The time dependence is `exp(-i E_n(k)t/hbar)`, so this map
must reproduce the LSWT frequency `E_n(k0)/hbar` before any OAM comparison is
interpreted.

## 2. What the per-sublattice mesh measures

Take a narrow packet centred at `k0`, with a slowly varying envelope of
winding `l`:

```
    beta_n(R) = A(R-R0) exp(+i l theta_(R-R0)) exp(+i k0.R).
```

At leading order, after averaging out the particle-hole interference at
`2 E_n/hbar`, define (with the common HP prefactor suppressed)

```
    Q_s = |u_sn(k0)|^2 + |v_sn(k0)|^2
    J_s = |u_sn(k0)|^2 - |v_sn(k0)|^2
    Q   = sum_s Q_s,       J = sum_s J_s.
```

For the unit-moment field used by C1, the sublattice contribution to both
`Q_s` and `J_s` is additionally multiplied by `2/S_s`; for an unnormalised
spin field it is multiplied by `2*S_s`. A common prefactor cancels from all
ratios below, and the honeycomb check has uniform `S`, so the suppressed form
is sufficient there.

The `J_s` sign is the spatial-momentum sign: the particle term has phase
`+k0.r`, while the hole term has phase `-k0.r`. A mesh that triangulates each
sublattice independently differentiates the envelope and this plane-wave
phase on each sublattice, but never differentiates across an A--B edge. With
the envelope-cell centroid as reference, it therefore gives

```
  Lambda_sub,env(l) = (J/Q) l
                    + [ sum_s J_s (tau_s x k0)_z ] / Q.       (1)
```

For a particle-conserving band (`v = 0`), which is the honeycomb oracle used
for the present bridge, this reduces to the requested lever-arm result:

```
  Lambda_sub,env(l) = l
                    + [ sum_s |u_sn|^2 (tau_s x k0)_z ]
                      / [ sum_s |u_sn|^2 ].                  (2)
```

This is the value about the cell/envelope origin. A different fixed origin
also adds the usual drift term `(R_packet - x0) x P`, as required by C3.

There is an important distinction for the output column actually named
`lambda_L_centroid`. The implementation computes the centroid from the
actual site positions, not from the Bravais-cell origins. To leading order
that centroid is

```
    R_site = R_env + tau_bar_Q,
    tau_bar_Q = [sum_s Q_s tau_s] / Q.
```

Consequently, the continuum limit of the global, actual-site centroid column
for the same packet is

```
  Lambda_sub,centroid(l) = (J/Q) l
    + [ sum_s J_s ((tau_s - tau_bar_Q) x k0)_z ] / Q.           (3)
```

For `v = 0`, the second term in (3) cancels exactly because
`tau_bar_Q = sum_s |u_s|^2 tau_s / sum_s |u_s|^2`. Thus a fixed particle-only
spinor has `Lambda_sub,centroid = l`, whereas its origin-referenced value
retains the raw lever in (2). For a hole-mixed mode, (3) is the correct
leading, cycle-averaged expression; instantaneous particle-hole cross terms
can oscillate at twice the mode frequency. A per-sublattice output block has
the same statement with that sublattice's own centroid.

This cancellation is not a contradiction of (2). It is the difference between
the envelope/cell origin and C3's centroid of the physical site weights. It is
also why an origin value must not be used as a translation-invariant bridge
observable.

## 3. Why this is not `F_n(k0)`

C9/C10 define the gauge-invariant LSWT quantity, in units of `hbar`, as

```
  F_n(k)/hbar = -1/2 Im[ T_n(k)^dagger eta dT_n(k)/dphi ],

  eta = diag(+1,...,+1,-1,...,-1),
```

with the ring average (equivalently Berry phase divided by `4*pi`) understood
in C10. This is a derivative of the band spinor around `k`; it is not the
algebraic intracell moment `tau_s x k`. The per-sublattice FEM gradient has no
triangle containing both sublattices, so it cannot recover the missing
intracell spinor derivative. Its direct comparison quantity is therefore
`Lambda_sub,env` or `Lambda_sub,centroid`, equations (1)--(3), including the
HP hole and norm factors when applicable.

The reciprocal-supercell particle-field identity fixes C14:

```
  Lambda_bridge(l) = l + Im[u^dagger d_phi u]
                    = l - 2 F_n(k0)/hbar.                    (4)
```

This is the target for the full angularly varying band packet, not for the
fixed-spinor control and not for the current per-sublattice FEM output. The
pointwise, gauge-dependent Berry connection must not be substituted for the
C10 ring quantity. Hole-mixed modes require the Nambu version of (4) and are
outside the current particle-only acceptance case.

## 4. Numerical check with `oracle_honey.py`

The independent honeycomb oracle was evaluated with `D = 0.1`, `S = 1`, and
the upper (band-1) eigenvector. This model is particle-conserving, so `v = 0`
and `Q = J = 1`.

| `k0` | `|u_A|^2` | `|u_B|^2` | `F_1(k0)/hbar` | raw lever in (2) |
|---:|---:|---:|---:|---:|
| `(0.35, 0)` | 0.49982089 | 0.50017911 | `-4.65e-8` | `-0.05053624` |
| `(1.00, 0)` | 0.49573979 | 0.50426021 | `-2.73e-5` | `-0.14556738` |
| `(3.00, 0)` | 0.34553428 | 0.65446572 | `-0.05136385` | `-0.56678394` |

For the same particle-only data, equation (3) gives a zero intracell term
about the actual global site centroid, while equation (2) gives the nonzero
raw-origin lever shown in the table. The oracle values are plainly not equal:
at `k0 = (3,0)`, for example, the Berry-flux value is `-0.05136` while the
raw per-sublattice lever is `-0.56678`. This numerically checks both the
lever-arm derivation and the fact that the present per-sublattice observable
cannot be identified with `F_n`.

## 5. Recommendation and gate

Offer both observables:

1. Keep the per-sublattice mesh for the existing trajectory contract. Report
   its origin and actual-site-centroid values with the interpretation in
   equations (1)--(3); do not relabel either as `F_n`.
2. Use the reciprocal-supercell packet and its analytic derivative as the
   C14/B5.4 convention oracle. It compares the full particle field with
   `l - 2F_n` and checks the independent `+1` envelope-winding shift.
3. Keep any future all-site production diagnostic separate until its
   discretisation and hole-sector conventions are specified.

C13/GA is accepted. C14 is confirmed by the analytic particle-field oracle;
G3 can use that oracle for the bridge convention while the existing
per-sublattice trajectory output remains explicitly non-`F_n`.

The reciprocal-supercell oracle resolves the former blocker: with the
documented `exp(+i k.r)` reconstruction, the particle-only spatial field
gives `lambda = l - 2 F_n` from the exact Fourier identity. This is now the
settled C14 convention.
