# Archived adaptive exchange coarse-graining history

This directory preserves historical design, implementation, and validation
documents for an experimental adaptive exchange coarse-graining
implementation. That production implementation was removed from
`gpu_hip_cu_ab_dip`.

The historical implementation remains available through Git history and the
`gpu_hip_cu_ab_cg` branch. Independent physics fixes discovered during the
campaign, including the DMI correctness work, and successful dipole/macrocell
infrastructure were deliberately retained on the cleaned branch.

These documents are historical evidence, not current UppASD usage
instructions. They may refer to source files, tests, input keywords, or
runtime APIs that no longer exist on the cleaned branch.
